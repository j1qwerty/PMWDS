# Configuration Requirements

## Database (PMWDS.Persistence)
- Entity Framework Core with SQL Server
- Microsoft.EntityFrameworkCore.SqlServer (10.0.5)
- Microsoft.EntityFrameworkCore.Tools (10.0.5)
- Microsoft.AspNetCore.Identity.EntityFrameworkCore (10.0.5)
- Dapper (2.1.35) for raw queries
- Connection string needed in appsettings.json

## Email Service ✅
- MailKit package added
- SMTP configuration needed in appsettings.json

## File Storage ✅
- Azure Blob Storage package added
- AzureStorageSettings configuration needed

## Background Jobs ✅
- Hangfire package added
- HangfireSettings configuration needed

## Caching ✅
- Redis package (Microsoft.Extensions.Caching.StackExchangeRedis) added
- Redis server needed

## Logging ✅
- Serilog package added

## Report Generation
- PDF library (QuestPDF, iTextSharp, etc.)
- Excel library (EPPlus, ClosedXML, etc.)

## AI Services (PMWDS.AI)
- OpenAI API Key required for AI chat and summarization
- Microsoft.ML (4.0.0) for ML tasks
- OpenAI (2.1.0) for ChatGPT integration
- Microsoft.Extensions.Http (10.0.0)
- Optional: Local ML model file path for delay prediction
- AISettings configuration needed in appsettings.json:
  - OpenAIApiKey: API key for OpenAI GPT models
  - OpenAIModel: Model name (default: gpt-4)
  - MLModelPath: Path to trained ML model file (optional)
  - UseLocalModel: Boolean to use local model instead of API (default: false)
  - RiskThreshold: Probability threshold for risk alerts (default: 0.7)
  - TrainingCronHour: Hour for scheduled model training (default: 2)

## API (PMWDS.API)
- JwtBearer (10.0.5) for authentication
- Swashbuckle (7.2.0) for Swagger
- Hangfire.AspNetCore (2.0.0) for background jobs
- Hangfire.SqlServer (2.0.0) for job storage
- Serilog.AspNetCore (8.0.0) for logging
- Serilog.Sinks.Seq (8.0.0) for structured logging
- FluentValidation.AspNetCore (11.3.0)
- AutoMapper.Extensions.Microsoft.DependencyInjection (12.0.1)
- MediatR.Extensions.Microsoft.DependencyInjection (11.1.0)
- appsettings.json configuration needed:
  - ConnectionStrings: Default, Redis, Hangfire
  - Jwt: Secret, Issuer, Audience, ExpiryMinutes
  - Email: Host, Port, Username, Password, SenderEmail, SenderName, UseSsl
  - AzureStorage: ConnectionString, ContainerName
  - AI: OpenAIApiKey, OpenAIModel, MLModelPath, UseLocalModel, RiskThreshold, TrainingCronHour
  - Hangfire: DashboardPath
- Seq: ServerUrl
- AllowedOrigins: Array of allowed CORS origins
- Serilog: MinimumLevel settings

## Infrastructure Phase Notes
- Background jobs expected by the infrastructure layer:
  - Deadline check job for reminders and overdue auto-escalation
  - Escalation re-check job after 48 hours
  - AI model training job
  - Scheduled project status report job
- Notification escalation role assumptions:
  - Level 1: `ProjectManager`
  - Level 2: `DepartmentHead`
  - Level 3 and above: `SuperAdmin`

## Persistence Phase Notes
- Database layer expects ASP.NET Identity tables for users, roles, and user-role joins.
- Persistence docs do not define seeders, default roles insertion, or default credentials yet.

## AI Phase Notes
- If `AISettings.MLModelPath` is empty or the file does not exist, delay prediction falls back to heuristic scoring.
- Chat session history is currently stored in memory; production persistence is noted as a future Redis-backed improvement.
