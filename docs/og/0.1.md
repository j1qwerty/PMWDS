## 🚀PMWDS 2.0 — Complete Solution Setup Guide
### 🚀part 1 — SOLUTION & PROJECT STRUCTURE
Step 1 — Create Solution
Open Terminal / Command Prompt and run:
``` bash
# Create root folder
mkdir PMWDS
cd PMWDS
# Create solution
dotnet new sln -n PMWDS
# Create all projects
dotnet new webapi -n PMWDS.API --no-openapi
dotnet new classlib -n PMWDS.Domain
dotnet new classlib -n PMWDS.Application
dotnet new classlib -n PMWDS.Persistence
dotnet new classlib -n PMWDS.Infrastructure
dotnet new classlib -n PMWDS.AI
# Add all projects to solution
dotnet sln add PMWDS.API/PMWDS.API.csproj
dotnet sln add PMWDS.Domain/PMWDS.Domain.csproj
dotnet sln add PMWDS.Application/PMWDS.Application.csproj
dotnet sln add PMWDS.Persistence/PMWDS.Persistence.csproj
dotnet sln add PMWDS.Infrastructure/PMWDS.Infrastructure.csproj
dotnet sln add PMWDS.AI/PMWDS.AI.csproj
```

 - Step 6 — Create Database Migration
```bash
# From solution root
cd PMWDS.API
dotnet ef migrations add InitialCreate \
 --project ../PMWDS.Persistence \
 --startup-project . \
 --output-dir ../PMWDS.Persistence/Migrations
dotnet ef database update \
 --project ../PMWDS.Persistence \
 --startup-project .
```

```bash
# From solution root

# Run the API
```
