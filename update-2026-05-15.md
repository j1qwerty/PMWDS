# Update 2026-05-15

## API Updates

- `GET /api/v1/system/database`: returns active database provider, connection source, fallback state, and selection log.
- `GET /api/v1/ai/settings`: now returns provider settings from database-backed provider records with `.env` default support.
- `POST /api/v1/ai/settings`: saves AI provider settings and API-key management preferences to the database.
- `POST /api/v1/users/{id}/profile-picture`: uploads a validated profile picture for the current user or by SuperAdmin.
- `PUT /api/v1/users/{id}/departments`: assigns a user to multiple departments and marks a primary department.
- `POST /api/v1/tasks/{id}/assign`: supports both single `assigneeId` and multiple `assigneeIds`.
- `POST /api/v1/tasks`: supports multiple initial task assignees through `assignedToUserIds`.
